# MGS_MascotPlayer Ver1.0.6

MML・MGSの音楽に合わせて、3Dマスコットが演奏するWindowsアプリです。

## 起動と必要なファイル

Windows 11 x64で検証しています。Microsoft Edge WebView2 Evergreen Runtimeが必要です。Windows版ZIPをフォルダごと展開し、`MGS_MascotPlayer.exe`を起動してください。

音楽の再生には、利用条件に従って正当に入手した外部ファイルをEXEと同じフォルダへ配置します。

| 操作 | 必要な外部ファイル |
| --- | --- |
| MMLのコンパイルと再生 | MGSC.COM v1.11、MGSDRV.COM v3.20 |
| 既存MGSの再生 | MGSDRV.COM v3.20 |

COM・VMD・楽曲データは同梱していません。COMなしでも曲の候補登録は可能で、再生時に不足を案内します。VMDを指定しない場合は、音楽とモデルの基本動作を利用できます。

SmartScreen等の警告が表示された場合は、配布元・SHA-256と利用者自身の判断を確認してください。WebView2の利用者通知は[こちら](docs/PRIVACY_NOTICE.txt)にあります。

## 基本操作

- 下部へマウスを近づけると再生パネルが表示されます。再生・一時停止・停止、曲送り・曲戻し、シーク、シャッフル・リピートを操作できます。
- 右上のプレイリストへMML/MGSを複数まとめてD&Dできます。追加だけでは自動再生しません。
- 透明な余白では背面ウィンドウを操作できます。左上の移動ハンドルで位置を変更します。
- 表示サイズ100%・向き0°の目盛りとリセットボタンがあります。スライダーの吸着はありません。
- シークバーにはPCM生成済み範囲と待機状態を表示します。初期の総時間が曲の生成に伴って補正されることがあります。

メイン画面の曲名はOLED風の文字表示です。文字とネオンは既存UIカラーテーマに連動し、暗いシャドウで輪郭を補助します。選択曲は太字と音符「♪」で強調し、長い曲名は横スクロールします。背景は透明です。UIテーマとオーディオビジュアライザーのカラープリセットは独立しています。

## 演奏セットとVMD

設定の「演奏セット」で曲一覧・モーションリスト・曲ごとの割り当てを管理します。同じ曲を複数回登録して別々のVMDを割り当てることもできます。追加した曲は初め「モーションなし」です。

VMDはファイル選択で複数登録でき、各VMDの基準BPMとループを編集します。同じパスの重複登録はできません。VMDのD&D登録はありません。登録削除は参照中の曲を確認して割り当てを解除し、VMD本体は削除しません。

編集はタブ・設定画面を閉じても実行中のセットに保持され、未保存変更をセット名の「*」で示します。「保存」「名前を付けて保存」でファイルへ保存してください。新規・読み込み・終了前には未保存変更を確認し、保存失敗時は現在の編集を保持します。元ファイルへ自動上書きしません。

再生中の曲・VMD・基準BPM・ループは、その演奏を開始した時点の情報を使います。編集中の変更は次回の対象曲再生から反映します。VMD未指定・読み込み失敗時は古いモーションを引き継がず、音楽を再生します。曲やVMDの素材本体はセットへ埋め込みません。

### 保存形式と旧版との互換性

**演奏セットはversion 3のJSON**（推奨拡張子`.mgsset.json`）で保存します。旧v1・v2も読み込めます。読み込むだけでは旧原本を変更しません。旧形式の原本への上書きは保護のため行わず、「名前を付けて保存」で別ファイルへ保存してください。

**Ver1.0.5以前のアプリはv3を読み込めません。** 旧版でも使うセットは原本を保管してください。詳細は[保存形式](docs/PERFORMANCE_SET_FORMAT.md)を参照してください。

## VMDごとの任意テキスト表示

「演奏セット」→「モーションリスト」で行を選択し、「選択中のVMD」の表示位置・表示タイミング・本文を編集します。内容は自由に指定でき、複数行に対応します。「表示しない」でも本文は保存されます。

表示位置は「表示しない」「左上に表示」「左下に表示」「右下に表示」の4種類です。左上は曲名一覧の先頭行上端へ、下側は操作パネルの上へ配置します。右下は最長行の幅のテキストボックス全体をプレイリスト領域の右端へ寄せ、内部の各行は左揃えです。右下は自動折り返しせず、長すぎる行をクリップします。

- 「常時表示」：対象が存在する間、表示を維持します。
- 「再生後しばらく表示」：5秒通常表示＋1秒フェードアウトで非表示になります。

一時停止・停止では最後の対象を再表示して保持し、再開・次曲開始では表示時間を最初から開始します。シークでは表示時間をリセットしません。再生中の編集は次回再生から反映します。VMD未指定・読み込み失敗・空欄では表示しません。

文字の暗いシャドウを強調し、行間を整理しています。文字はマウス操作を妨げません。URLはリンク化せず、表示文字から通信しません。詳細は[テキスト表示](docs/TEXT_DISPLAY.md)をご確認ください。

## オーディオビジュアライザーと表示設定

「表示・エフェクト」で円形・スペクトラム・オシロスコープを選択できます。5種類のカラープリセットと3段階の明るさを共用します。スペクトラムは16/32/64本、オシロスコープは振幅0.5〜4.0倍と発光ON/OFFを設定できます。音声gain・音量・PCMは変更しません。[操作の詳細](docs/VISUALIZER.md)。

## 設定と制約

「起動時に前回使用した演奏セットを読み込む」は初期値OFFです。ONでも前回保存済みの内容だけを読み込み、未保存編集は自動復元しません。一般設定は`%APPDATA%\MGS_MascotPlayer`配下に保存します。「設定を初期値に戻す」は一般設定を初期化し、演奏セットや素材ファイルは削除しません。

固定PMXモデルを使用します。任意モデルの読み込みはありません。全VMDの外観・衣装干渉を保証しません。静止時・曲切り替え時の髪などに微小な動きが生じる場合があります。

実OS200%表示、別のクリーンPC、外部機材による音声・映像遅延は未検証です。詳しくは[検証範囲](docs/VERIFICATION.md)を参照してください。
