# MGS_MascotPlayer Ver1.0.4 未公開候補（v036）

MML・MGSの演奏と、固定PMXマスコットのモーションを楽しむWindows用プレイヤーです。この版はユーザー承認前の候補で、公開済みVer1.0.3を置き換えません。

## 起動

Windows 11 x64で検証しています。Microsoft Edge WebView2 Evergreen Runtimeが別途必要です。ZIPをフォルダごと展開し、正当に入手したMGSC.COM v1.11とMGSDRV.COM v3.20をEXEと同じフォルダへ配置してください。COM・VMD・利用者の曲は同梱しません。MMLコンパイルはMGSC、音声生成はMGSDRVが必要です。既存MGSの再生はMGSDRVだけが必要です。

SmartScreen等の警告は配布元・SHA-256と利用者自身の判断を確認してください。WebView2の利用者通知は docs/PRIVACY_NOTICE.txt にあります。

## 演奏セット

設定の「演奏セット」で、曲一覧とモーションリストを一体として管理します。保存済みデータにある複数プレイリストの情報は互換性のため保持し、画面では現在選択されている曲一覧を編集します。曲の登録項目は安定したIDで識別するため、同じ曲ファイルを複数回登録し別のVMDを割り当てることもできます。曲追加の初期値は「モーションなし」です。

「モーションリスト」のVMD追加は複数ファイル選択に対応します。新規BPMは120、内容のBPM履歴があれば履歴値を優先します。BPM・ループはリストで編集し、曲に最大1件を割り当てます。同じパスの重複登録はできません。異なる場所の同名VMDは別登録です。VMDのD&D登録はありません。

VMD登録解除時は参照中の曲を確認し、承認後に関連する割り当てを「モーションなし」にします。元ファイルは削除しません。

## 編集と保存

設定の変更や透過プレイリストへのD&Dは実行中のセットへ反映します。設定を閉じたり別タブへ移っても保持し、未保存変更はセット名の `*` で示します。設定を閉じるだけで編集を破棄する動作はありません。

- 保存：現在の保存先へ保存。新規セットなら保存先を選択。
- 名前を付けて保存：別ファイルへ保存。
- 読み込み：保存済みセットを一体で読み込み。
- 新規：空のセットを作成。

新規・読み込み前に未保存変更があれば「保存して続行」「保存せず続行」「キャンセル」を選びます。保存失敗・選択キャンセルでは切り替えません。読み込み失敗時も現在の編集を保持します。終了時にも未保存セットの保存確認があり、保存失敗なら終了を中止します。保存先ファイルへの自動上書きはしません。

保存形式はversion 1のJSON（推奨拡張子 `.mgsset.json`）。曲・VMDのパスと設定を保持し、素材本体を埋め込みません。ファイル移動時は利用者が参照先を管理してください。

## 音声とVMD

曲変更時は方式Bで音楽とVMDの準備を待ち、両方の準備後に再生します。新しいVMD先読み・専用キャッシュは追加していません。既存PCMシークキャッシュは維持します。

VMD未指定・読み込み失敗時は音楽のみ再生します。失敗時は古いVMDを引き継がず、モデルを基準姿勢へ戻します。登録と割り当ては保持し、次回同じ曲を再生するときに再試行します。復旧しても曲の途中で自動適用しません。読込状態をモーションリストに表示します。

再生中の曲・VMD・BPM・ループはその演奏の開始時点の情報を保持します。編集・曲削除・新規セット・別セット読み込みでも、その演奏は継続し、次曲から最新のセットを使います。空セットなら次曲はありません。シーク・一時停止・再開は同じVMDと音声時計を維持し、独立したモーション時計や姿勢ブレンドは使いません。

## 起動と旧設定の移行

「起動時に前回使用した演奏セットを読み込む」は初期値OFF。OFFは空セット、ONは前回セットの保存済み内容だけを読み込みます。未保存編集は自動復元しません。セットファイルは削除しません。

旧Ver1.0.3設定がある初回だけ、旧設定の原本コピーと移行セットを保存し、旧VMD/BPM/ループを全登録曲へ関連付けて表示します。VMD欠落・破損でも情報を保持します。初回の表示だけが空セット起動の例外で、次回以降はチェック設定に従います。移行記録により、古い設定バックアップへ復帰しても二重移行を防ぎます。

一般設定は既存保存先 `%APPDATA%/MGS_MascotPlayer/validation/code-audit-refactor-v016` を維持します。調査用の隔離コピーだけはEXE横のvalidation-data-root.jsonで別データ領域を使います。この候補の通常版にはその検証マーカーを含めません。「設定を初期値に戻す」は演奏セット・素材を保持して一般設定を初期化します。

## 基本操作・制約

右上へMML/MGSを複数D&Dで追加できます。追加のみでは自動再生しません。MMLは拡張子だけで判定せず、COMなしでも候補登録し、再生時に不足を案内します。下部マウスオーバーで操作パネル、左上ハンドルで移動、透明余白は背面操作。シークバーは実際のPCM生成済み範囲と待機表示に対応します。gain・5色テーマ・表示サイズ・向きは従来どおりです。

固定PMX・Ver1.0.3前腕IKを維持します。任意モデル対応はありません。全VMDの外観や衣装干渉の解消は保証しません。200%倍率を選べない実機と別クリーンPCの未検証は、同梱検証結果で明示します。今回の合否は docs/VERIFICATION.md を参照してください。
