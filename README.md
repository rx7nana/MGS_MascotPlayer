# MGS_MascotPlayer Ver1.0.4

MML・MGSの演奏と、3Dマスコットのモーションを楽しめるWindows用音楽プレイヤーです。

曲ごとに異なるVMDモーションを割り当て、音楽の再生位置やBPMに合わせてマスコットを動かせます。

現在は内蔵の固定PMXモデルに対応しています。

![動作確認画面例](docs/images/application.png)

## 主な機能

- MML・MGSファイルの再生
- 3Dマスコットの表示とVMDモーション再生
- 音楽とモーションのBPM同期
- 曲ごとのVMD割り当て
- VMDごとの基準BPM・ループ設定
- プレイリストとモーションリストをまとめた演奏セット管理
- 複数の演奏セットの保存・読み込み
- シャッフル・リピート・シーク・一時停止
- 透明ウィンドウ、表示サイズ・向き・テーマの変更
- ショルダーキーボードの演奏動作と鍵盤発光

## 動作環境

- Windows 11 x64（検証環境）
- Microsoft Edge WebView2 Runtime
- MGSC.COM v1.11
- MGSDRV.COM v3.20

MGSC.COMとMGSDRV.COMは同梱していません。別途、正規に入手してください。

MMLのコンパイルにはMGSC.COM、音声生成にはMGSDRV.COMが必要です。既存MGSファイルの再生にはMGSDRV.COMが必要です。

## インストール・起動

1. [GitHub Releases](https://github.com/rx7nana/MGS_MascotPlayer/releases/latest)からWindows版ZIPをダウンロードします。
2. ZIPを新しいフォルダへ展開します。
3. MGSC.COM v1.11とMGSDRV.COM v3.20を、MGS_MascotPlayer.exeと同じフォルダに配置します。
4. MGS_MascotPlayer.exeを起動します。

WebView2 Runtimeがインストールされていない場合は、[Microsoft公式ページ](https://developer.microsoft.com/microsoft-edge/webview2/)から導入してください。

## 演奏セット

設定画面の「演奏セット」で、プレイリストとモーションリストをまとめて管理できます。

### プレイリスト

- MML・MGSファイルの追加・削除・並べ替え
- 曲ごとのVMDモーション指定
- 同じ曲ファイルの複数登録
- 新規追加曲の初期設定は「モーションなし」

### モーションリスト

- VMDファイルの登録・削除
- 複数VMDファイルの一括登録
- VMDごとの基準BPM設定（新規登録時は120）
- VMDごとの自動ループON/OFF
- VMD読み込み状態の確認

VMDの登録解除は、リストから対象を選択して「削除」を押します。

使用中のVMDを登録解除すると、確認後に該当曲の割り当てが「モーションなし」になります。元のVMDファイルは削除されません。

## 演奏セットの保存・読み込み

プレイリストとモーションリストは、1つの演奏セットとして保存します。

- **新規**：空の演奏セットを作成
- **読み込み**：保存済みの演奏セットを読み込む
- **保存**：現在の演奏セットを保存
- **名前を付けて保存**：別名の演奏セットとして保存

複数の演奏セットを作成し、用途に応じて切り替えられます。

設定画面を閉じても、アプリ実行中は編集内容が維持されます。未保存の変更がある場合、セット名の末尾に `*` が表示されます。

アプリ終了時に未保存の変更があれば、保存するかどうかを確認します。

保存形式は `.mgsset.json` です。曲やVMDの元ファイルは保存データに含まれないため、ファイルの移動・削除には注意してください。

### 起動時の読み込み

「起動時に前回使用した演奏セットを読み込む」をONにすると、次回起動時に前回使用した演奏セットの保存済み内容を読み込みます。

初期設定はOFFです。OFFの場合は、空の演奏セットから開始します。

旧Ver1.0.3の設定がある場合は、初回起動時に既存プレイリストとVMD設定を引き継ぐ移行処理が行われます。

## 音楽とモーションの同期

曲の再生開始時に音声とVMDの準備を行い、両方が揃ってから同期して再生します。

シーク・一時停止・再開時も、音声の再生位置を基準としてモーションを同期させます。

VMDを指定していない曲や、VMDの読み込みに失敗した曲は、音楽のみ再生します。

読み込みに失敗したVMDの登録・割り当ては保持され、次回その曲を再生するときに再試行されます。

再生中に曲やVMDの設定を変更した場合は、次回の再生から反映されます。

## 基本操作

- 画面右上の受付領域へMML・MGSファイルをドラッグ＆ドロップして追加
- 画面下部にマウスを近づけると再生操作パネルを表示
- 左上のハンドルでウィンドウを移動
- シークバーで再生位置を変更
- 設定画面から音量・テーマ・表示サイズ・向きなどを調整

ファイルを追加しただけでは自動再生されません。

## 注意事項

- 現在は内蔵の固定PMXモデルのみ対応しています。
- 任意PMXモデルの読み込みには未対応です。
- VMDとモデルの組み合わせによっては、モーションや衣装の表示が不自然になる場合があります。
- Windows 11 x64以外の環境での動作は保証していません。
- Windows SmartScreen等の警告が表示された場合は、配布元とファイルの安全性を確認してください。

WebView2の利用者向け通知は [PRIVACY_NOTICE.txt](docs/PRIVACY_NOTICE.txt) を参照してください。
