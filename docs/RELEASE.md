# 配布構成

Windowsパッケージはフォルダごと展開します。外部vgm2wav.exe・COM、VMD・楽曲・利用者設定、検証用EXE・ログ・WAVは含めません。必要な外部ファイルはREADMEを参照してください。

対応ソースにはビルド設定・自作コード・既存第三者ソース/原通知・承認済み固定素材を含めます。source/build、取得済み依存キャッシュ、ローカル設定は含めません。

演奏セットはv4保存、旧v1～v3読み込み。正式Ver1.0.6以前ではv4を読めません。旧原本を保管し、別名保存してください。

現段階はVer1.1.0の公開判断前の候補です。アプリ表示・packageは1.1.0、Windows数値版は1.1.0.0へ更新しています。公開操作/Commit/Push/Releaseは実施していません。
