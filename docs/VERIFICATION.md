# Ver1.0.1候補の検証

v029でVMDの初期表示・初期化・復元・欠落/不正ファイル時の継続処理を修正し、固定した既存ツールチェーンでホスト・音声コア・UIをビルドしました。依存ライブラリの更新はありません。ソースと生成EXEの対応はSOURCE_PROVENANCE.jsonを参照してください。ビット単位で再現可能なビルドという主張はしていません。

実操作と再起動の両方で、VMD未選択・BPM未設定、選択したVMD/BPMの復元、初期化後に履歴が復活しないことを確認しました。回復用バックアップを使った場合も初期化状態を維持します。欠落・破損VMDでモデルを表示し、VMDなしで音楽と鍵盤発光を確認しました。

PCM24ケース、ネイティブ優先生成5地点、loop/fade9ケース、BPM/状態復元5ケース、不連続キャッシュの全PCM比較、Windowsシーク回帰15項目が合格しました。実マウスでVMD再生・設定・gain・5色テーマ・D&D2/5/10・クリック透過・移動・スライダーを確認しました。100/125/150/175%は正常、200%は選択できず未検証です。

300秒曲50%への冷キャッシュシークを、同じ実機・新規起動・同じ7回測定で比較しました。中央値は旧公開版1472.5ms、v029 1474.9ms（約+0.16%）。別途、監視・実操作後の測定は1797.6msでしたが条件が異なるため分けて記録しています。120秒の連続再生は平均59.91FPS、音声不足0、欠落サンプル0。正常終了後の追跡226プロセスが全て終了しました。

音声生成・シーク仕様・固定依存・モデル・アイコンを維持し、PCM一致と回帰が成功したため、今回3時間試験は繰り返していません。v025の過去3時間試験は別時点の記録です。別クリーンPCは未検証です。

検証用の制御フラグが実操作のhoverを抑制した問題は検証コピーだけを修正し、設定を閉じた後の再表示も利用者が確認済みです。この検証フラグや試験用COM/VMD/設定/ログは配布物に含めません。
