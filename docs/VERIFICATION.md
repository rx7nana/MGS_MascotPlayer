# Ver1.0.6 検証範囲

承認済み機能・配置・音声処理を継承し、この最終調整はバージョン表示、Windowsリソース、公開用文書、ビルド設定に限定しています。

ソース試験、全体ソースビルド、再生成音声の比較、ZIPのCRC/全エントリーSHA、隔離起動/正常終了/追跡プロセス終了を確認します。実行結果は配布物と分離した最終検証報告へ保存します。

前の承認工程で100/125/150/175%実機操作を確認しています。今回その実機操作全体や長時間耐久は繰り返しません。実OS200%、別クリーンPC、外部機材による音声・映像遅延は未検証。全VMD外観・衣装干渉は保証しません。過去の試験を今回再実施した扱いにはしません。
