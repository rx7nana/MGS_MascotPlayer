# 検証範囲

VGM先行再生を含む公開候補の構成・文書・再ビルド・回帰を確認します。再実施した結果は配布物と分離した監査報告に記録します。

基準候補ではWotG先行再生、10分VGMの全区間実時間再生、MGS PCM/イベント、VMD時計と描画フレーム、保存形式の自動試験を確認しています。過去の試験を今回再実施した扱いにはしません。

物理スピーカー聴感・実マウスD&D/キャンセル・Windows実DPI等は未確認部分があります。実OS200%、別のクリーンPC、外部機材による音声/映像遅延、全VMDの外観/衣装干渉は保証しません。自動試験/実WebView2/物理操作を区別します。
