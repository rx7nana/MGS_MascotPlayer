# Ver1.0.5 検証範囲

承認済みv041の機能・音声処理・UIを継承し、今回の変更はバージョン表示・Windowsリソース・配布文書に限定しています。過去の試験を今回の再実施として扱いません。

v041ではPCM比較、音声不足0、VMD同期、表示3方式、カラー・明るさの独立性、実入力を確認しました。実機100/125/150/175%を確認、200%は選択できず未検証です。ブラウザーの200%相当検証は実機試験とは別です。

別の開発ツール未導入PCと物理スピーカーを用いた音声・映像遅延測定は未実施です。すべてのVMDの外観・衣装干渉は保証しません。モーション未割当時や曲切替時にも髪等が微小に動く場合があり、既存の動作を維持しています。

今回のビルド・ソース差分・ZIP整合性・隔離起動終了の結果は配布物と分離した最終検証報告に記録します。
