# VMDごとの任意テキスト表示

演奏セット→モーションリストで行を選び、表示位置・表示タイミング・複数行本文を編集します。内容は自由です。最大65,536 UTF-16コード単位。v3ファイルのcreditText/textPosition/textModeへ保存します。

左上は曲名一覧の先頭行上端（通常119 CSS px）。左下は左20 CSS px。下側はいずれも操作パネル上12 CSS pxを基準とします。右下は実フォントの最長行幅（max-content）へボックス幅を合わせ、プレイリスト領域の右端へ寄せ、各行は左揃え。右下は折り返さず、画面内の幅へ制限してクリップします。ほかの左側配置は従来の折り返しを使用します。

文字は12px、行間17px、従来のフォント・色・縁取りを使用し、暗い4方向の1pxシャドウで輪郭を強調します。テキストには新しいネオンを付けません。pointer-events:noneで操作を奪いません。

「常時表示」は時間で非表示になりません。「再生後しばらく表示」は5秒表示＋1秒フェード。一時停止/停止で表示保持、再開で6秒を最初から開始。シークでは時間をリセットしません。次曲VMDなし・読み込み失敗・空欄・表示しないの場合は非表示です。再生中の編集は次回の対象曲再生から反映します。

旧v2の表示ONは右下、OFFは表示しない、タイミングは常時表示へ移行します。元のファイルは読み込みだけでは変更せず、旧形式原本への上書きを保護します。
