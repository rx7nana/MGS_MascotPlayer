# 改変版のアイコン差し替え

公式アイコンは公式版専用です。第三者の改変版を配布する場合は、権利を持つ独自アイコンへ差し替えてください。これは素材の条件であり、自作プログラムのMITを変更しません。

| 用途 | ファイル | ビルドの参照 |
|---|---|---|
| EXE・Windowsウィンドウ等 | assets/windows/MGS_MascotPlayer.ico | assets/windows/app-icon.rcの101 ICON。tools/build.pyがwindresでリソース生成し、ホストへリンク |
| 実行時UIアイコン | assets/ui/icon.png | tools/build.pyが生成app/web/icon.pngへコピー |

1. 独自のWindows用マルチサイズICOを、同じパス・ファイル名で配置します。
2. 独自のPNGをassets/ui/icon.pngへ配置します。変更後の両ファイルについて利用・再配布権を確認してください。
3. docs/BUILD.mdのビルド手順を実行します。RCのファイル名を変えず差し替える方法であれば、アプリの実装変更は不要です。
4. 生成物が独自アイコンを持つことをWindowsで確認してください。キャッシュの旧表示と実際の埋め込みを区別します。
5. README等へ非公式改変版、元プロジェクト名、素材著作権者rx7nana、素材条件を表示し、MIT・第三者通知・ASSET-LICENSE.mdを同梱してください。

この参照経路はv026の実ビルドおよびv027の再ビルドで確認しています。今回、別デザインへの実差し替え・そのWindows表示試験は行っていません。既存の公式アイコンとアプリ実装は変更していません。
